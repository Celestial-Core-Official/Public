# Public

A shared space for **Celestial Core** members to store and access public files.

## What is this?

This repo is used by Celestial Core members to share files publicly — resources, assets, configs, or anything else the org wants to make available.

## Guidelines

- Only Celestial Core members can add or modify files
- Keep files organized and clearly named
- No sensitive or private information
